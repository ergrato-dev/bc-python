# Libros y Documentación — Semana 33: Performance y Optimización

## Documentación oficial (gratuita y online)

| Recurso | Descripción |
|---------|-------------|
| [Python — The Python Profilers (docs)](https://docs.python.org/3/library/profile.html) | Documentación oficial de `cProfile` y `pstats` — opciones, stats, uso programático |
| [Python — tracemalloc (docs)](https://docs.python.org/3/library/tracemalloc.html) | Tracing de allocaciones de memoria — snapshots, estadísticas por línea |
| [redis-py Documentation](https://redis-py.readthedocs.io/en/stable/) | Documentación completa del cliente Python — comandos, connection pools, typing |
| [Redis Commands Reference](https://redis.io/commands/) | Referencia de todos los comandos Redis: GET, SETEX, SCAN, INFO, etc. |

## Guías prácticas (gratuitas)

| Recurso | Descripción |
|---------|-------------|
| [Python Speed — High Performance Python Tips](https://wiki.python.org/moin/PythonSpeed) | Wiki oficial con técnicas de optimización: generators, builtins, profiling |
| [Real Python — Python Timer](https://realpython.com/python-timer/) | Timeit, time.perf_counter y decoradores de timing — guía completa |
| [pytest-benchmark Docs](https://pytest-benchmark.readthedocs.io/en/stable/) | Documentación de pytest-benchmark: fixtures, opciones, comparación y exportación |
| [py-spy GitHub](https://github.com/benfred/py-spy) | README completo de py-spy: instalación, comandos, flame graphs, modo top |
