# Ebooks gratuitos — Semana 30

Libros completos que sus autores publican gratis en la web, en inglés.

| Libro | Para qué |
|---|---|
| [Statistics Done Wrong](https://www.statisticsdonewrong.com/) (Alex Reinhart) | Corto y directo: significativo frente a importante, comparaciones múltiples, el jardín de los senderos. Casi toda la teoría de esta semana, con casos reales |
| [Fundamentals of Data Visualization](https://clauswilke.com/dataviz/) (Claus O. Wilke) | Cómo elegir un gráfico, cómo mostrar la incertidumbre y cómo titularlo. La teoría 04 |
| [Think Stats, 3.ª edición](https://allendowney.github.io/ThinkStats/) (Allen B. Downey) | Estadística con Python y pandas, desde la exploración hasta las pruebas de hipótesis. Repaso de las semanas 28 a 30 |
