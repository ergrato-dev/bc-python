# Webgrafía — Semana 30

Casi todo en inglés, de la documentación oficial de cada proyecto. Las guías siguen la última versión; si algo no coincide con SciPy 1.18 o matplotlib 3.11, manda lo que ves al ejecutar.

| Recurso | Para qué |
|---|---|
| [SciPy: `false_discovery_control`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.false_discovery_control.html) | Benjamini-Hochberg y Benjamini-Yekutieli, con un ejemplo. La teoría 03 y `compare_all` |
| [SciPy: `ttest_ind`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html) | `equal_var=False` (Welch) y `confidence_interval`. La teoría 02 |
| [matplotlib: `Axes.errorbar`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.errorbar.html) | `xerr` simétrico y asimétrico, `fmt` y `capsize`. La teoría 04, sección 3 |
| [matplotlib: `Figure.savefig`](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.savefig.html) | `metadata` y los formatos. La teoría 04, sección 5 |
| [matplotlib: Customizing with rcParams](https://matplotlib.org/stable/users/explain/customizing.html) | `svg.hashsalt` y `svg.fonttype`, en el `matplotlibrc` de ejemplo. El ejercicio 03 |
| [GitHub: Organizing information with tables](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/organizing-information-with-tables) | Tablas en Markdown, alineación y cómo escapar `\|`. La teoría 04, sección 4 |
| [Python: `difflib`](https://docs.python.org/3/library/difflib.html) | `unified_diff`, el formato de `git diff`. El ejercicio 04, paso 5 |
| [Multiple comparisons problem](https://en.wikipedia.org/wiki/Multiple_comparisons_problem) | El problema, con la fórmula 1 − (1 − α)^m y las correcciones. La teoría 03 |
| [False discovery rate](https://en.wikipedia.org/wiki/False_discovery_rate) | FDR frente a FWER, y el procedimiento de Benjamini-Hochberg paso a paso. La teoría 03, sección 3 |
| [Paradoja de Simpson](https://es.wikipedia.org/wiki/Paradoja_de_Simpson) (en español) | El caso de las admisiones de Berkeley y otros. La teoría 02, sección 3, y el ejercicio 01 |
| [The garden of forking paths](http://www.stat.columbia.edu/~gelman/research/unpublished/forking.pdf) (Gelman y Loken) | El artículo que da nombre al jardín de los senderos que se bifurcan. La teoría 01, sección 4 |
| [xkcd 882: Significant](https://xkcd.com/882/) | Las comparaciones múltiples en una viñeta: veinte colores de gominolas |
| [Fundamentals of Data Visualization: Visualizing uncertainty](https://clauswilke.com/dataviz/visualizing-uncertainty.html) | Intervalos, barras de error y por qué las barras de medias engañan. El ejercicio 03 |
