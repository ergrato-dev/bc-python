# Webgrafía — Semana 25

Todo en inglés, de la documentación oficial de pandas salvo donde se indica. Comprueba arriba de cada página que es la de la versión 3.

| Recurso | Para qué |
|---|---|
| [Group by: split-apply-combine](https://pandas.pydata.org/docs/user_guide/groupby.html) | Todo sobre `groupby`: agregación con nombre, `transform`, `filter`, `apply` y las claves que faltan. La referencia de la teoría 01 |
| [How to calculate summary statistics](https://pandas.pydata.org/docs/getting_started/intro_tutorials/06_calculate_statistics.html) | Tutorial corto con dibujos: `groupby`, `agg` y `value_counts`. Buen repaso antes del ejercicio 01 |
| [Merge, join, concatenate and compare](https://pandas.pydata.org/docs/user_guide/merging.html) | `concat`, `merge`, `join` y `validate`, con diagramas de cada `how`. La teoría 02 en profundidad |
| [`pandas.DataFrame.merge`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.merge.html) | Todos los parámetros de `merge`: `on` con nombres de índice, `suffixes`, `indicator` y `validate` |
| [How to combine data from multiple tables](https://pandas.pydata.org/docs/getting_started/intro_tutorials/08_combine_dataframes.html) | Tutorial corto de `concat` y `merge` con datos de calidad del aire |
| [Reshaping and pivot tables](https://pandas.pydata.org/docs/user_guide/reshaping.html) | `pivot`, `pivot_table`, `melt`, `stack`, `unstack` y `crosstab`. La referencia de la teoría 03 |
| [How to reshape the layout of tables](https://pandas.pydata.org/docs/getting_started/intro_tutorials/07_reshape_table_layout.html) | Formato largo y ancho con dibujos: `pivot`, `pivot_table` y `melt` |
| [Time series / date functionality](https://pandas.pydata.org/docs/user_guide/timeseries.html) | `to_datetime`, `date_range`, los textos de `freq`, `resample` con `origin`, `closed` y `label`, y las zonas horarias. La referencia de la teoría 04 |
| [Time deltas](https://pandas.pydata.org/docs/user_guide/timedeltas.html) | `Timedelta`: qué textos acepta y cómo se opera. Lo que usa `duration` |
| [How to handle time series data with ease](https://pandas.pydata.org/docs/getting_started/intro_tutorials/09_timeseries.html) | Tutorial corto de fechas, `.dt` y `resample` |
| [Windowing operations](https://pandas.pydata.org/docs/user_guide/window.html) | `rolling` por filas y por tiempo, `expanding` y `ewm` |
| [`pandas.DataFrame.resample`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.resample.html) | Los parámetros de `resample`, con ejemplos de `origin` y de los bordes de cada periodo |
| [strftime() and strptime() format codes](https://docs.python.org/3/library/datetime.html) (documentación de Python) | La tabla de códigos de formato (`%d`, `%m`, `%Y`, `%H`...) que usa `to_datetime(format=...)`. Busca la sección con ese título |
| [Tidy Data](https://www.jstatsoft.org/article/view/v059i10) (Hadley Wickham, Journal of Statistical Software) | El artículo que explica por qué el formato largo es el bueno para calcular. Escrito para R; las ideas valen igual |
