# Libros y Documentación — Semana 31: Clean Architecture y DDD

## Libros gratuitos (acceso libre)

| Recurso | Descripción |
|---------|-------------|
| [Architecture Patterns with Python](https://www.cosmicpython.com/) | Libro completo gratuito online — TDD, DDD, Clean Architecture en Python. El referente de esta semana |
| [DDD Reference — Eric Evans](https://www.domainlanguage.com/ddd/reference/) | Resumen oficial del libro DDD (PDF gratuito) — Building Blocks, Strategic Patterns |

## Libros de pago (imprescindibles, capítulos disponibles gratis)

| Recurso | Descripción |
|---------|-------------|
| [Clean Architecture — Robert C. Martin](https://www.amazon.com/Clean-Architecture-Craftsmans-Software-Structure/dp/0134494164) | El libro de Uncle Bob — capítulos 1-5 y 20-28 son los más relevantes para esta semana |
| [Domain-Driven Design — Eric Evans](https://www.amazon.com/Domain-Driven-Design-Tackling-Complexity-Software/dp/0321125215) | El libro original del DDD — densa pero fundamental; caps. 1-5 para empezar |
| [Implementing Domain-Driven Design — Vaughn Vernon](https://www.amazon.com/Implementing-Domain-Driven-Design-Vaughn-Vernon/dp/0321834577) | Más práctico que Evans — con ejemplos de código |

## Artículos y recursos adicionales

| Recurso | Descripción |
|---------|-------------|
| [Martin Fowler — Catalog of Patterns of Enterprise Application Architecture](https://martinfowler.com/eaaCatalog/) | Catálogo completo: Repository, Unit of Work, Service Layer, Domain Model |
| [Python Patterns Guide](https://python-patterns.guide/) | Patrones GoF en Python moderno — con ejemplos tipados |
| [dependency-injector Documentation](https://python-dependency-injector.ets-labs.org/) | Documentación completa exportable — providers, wiring, testing |

> **Destacado:** [Architecture Patterns with Python](https://www.cosmicpython.com/) (Harry Percival & Bob Gregory, O'Reilly) es el libro que conecta DDD + Clean Architecture + TDD con Python real. Gratuito y online. Los capítulos 1 (Domain Model), 2 (Repository), 4 (Service Layer) y 5 (High Gear / Low Gear TDD) son lectura obligatoria para esta semana.
