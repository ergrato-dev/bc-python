# Webgrafía — Semana 14

| Recurso | Para qué |
|---|---|
| [pytest: fixtures](https://docs.pytest.org/en/stable/how-to/fixtures.html) (en inglés) | Fixtures que piden fixtures, `yield`, `scope`, `conftest.py` y fábricas, con ejemplos de cada uno: la teoría 01 |
| [pytest: parametrize](https://docs.pytest.org/en/stable/how-to/parametrize.html) (en inglés) | `parametrize`, `ids`, `pytest.param` y combinaciones: la teoría 02 |
| [pytest: skip y xfail](https://docs.pytest.org/en/stable/how-to/skipping.html) (en inglés) | Todas las formas de saltar un test o marcar un fallo conocido, y `strict` |
| [pytest: logging](https://docs.pytest.org/en/stable/how-to/logging.html) (en inglés) | La fixture `caplog` y cómo muestra pytest el registro de los tests que fallan |
| [Hypothesis: quickstart](https://hypothesis.readthedocs.io/en/latest/quickstart.html) (en inglés) | El primer test con `@given`, las estrategias más usadas y qué hacer con un contraejemplo: la teoría 03 |
| [Hypothesis: documentación](https://hypothesis.readthedocs.io/en/latest/) (en inglés) | La referencia de todas las estrategias, `settings`, los *health checks* y la base de datos |
| [What is property based testing? — Hypothesis](https://hypothesis.works/articles/what-is-property-based-testing/) (en inglés) | Qué es una propiedad y en qué se diferencia de un test de ejemplos, en un artículo corto |
| [Choosing properties for property-based testing — Scott Wlaschin](https://fsharpforfunandprofit.com/posts/property-based-testing-2/) (en inglés) | Los patrones de propiedades (ida y vuelta, invariantes, oráculo...) con dibujos. Los ejemplos están en F#, pero las ideas son las mismas |
| [`unittest.mock`](https://docs.python.org/es/3.14/library/unittest.mock.html) (en español) | `Mock`, `MagicMock`, `patch`, `side_effect` y `autospec`: la teoría 04. Busca la sección "Dónde parchear" |
| [Mocks Aren't Stubs — Martin Fowler](https://martinfowler.com/articles/mocksArentStubs.html) (en inglés) | La diferencia entre *stub*, *fake* y *mock*, y dos maneras de probar: por el estado o por las llamadas |
| [coverage: cobertura de ramas](https://coverage.readthedocs.io/en/latest/branch.html) (en inglés) | Qué es una rama parcial y cómo leer `34->36`: la teoría 05 |
| [coverage: configuración](https://coverage.readthedocs.io/en/latest/config.html) (en inglés) | Todas las opciones de `[tool.coverage]`: `source_pkgs`, `branch`, `fail_under`, `exclude_also` |
| [Logging HOWTO](https://docs.python.org/es/3.14/howto/logging.html) (en español) | Niveles, loggers, manejadores y formato. Lee "Configurando Logging para una biblioteca": la regla de que el paquete no configura |
