# Webgrafía — Semana 22

| Recurso | Para qué |
|---|---|
| [Los perfiladores de Python](https://docs.python.org/3/library/profile.html) (en inglés) | La documentación de `cProfile` y `pstats`: las opciones de `python -m cProfile`, las columnas del informe y los métodos de `Stats`. La teoría 02 |
| [`timeit`](https://docs.python.org/3/library/timeit.html) (en inglés) | `repeat`, `autorange` y la orden `python -m timeit`, con la advertencia de usar el mínimo. El ejercicio 01 |
| [`time`](https://docs.python.org/3/library/time.html) (en inglés) | La diferencia entre `perf_counter`, `process_time` y `time`. La teoría 01, sección 3 |
| [Opciones de la línea de órdenes](https://docs.python.org/3/using/cmdline.html) (en inglés) | Busca `-X importtime`: cómo medir lo que tarda cada importación. La teoría 04, sección 6 |
| [`tracemalloc`](https://docs.python.org/3/library/tracemalloc.html) (en inglés) | Para ver qué líneas de tu código reservan memoria, cuando el tiempo no es el problema |
| [py-spy](https://github.com/benfred/py-spy) (en inglés) | El README del proyecto: `record`, `top` y `dump`, los permisos en cada sistema y las preguntas frecuentes. La teoría 03 |
| [Flame Graphs](https://www.brendangregg.com/flamegraphs.html) (en inglés) | De Brendan Gregg, quien los inventó: cómo se leen y por qué el eje horizontal no es el tiempo |
| [speedscope](https://www.speedscope.app/) (en inglés) | Un visor de perfiles en el navegador. Graba con `py-spy record -f speedscope` y arrastra el archivo |
| [Ley de Amdahl](https://es.wikipedia.org/wiki/Ley_de_Amdahl) (en español) | La fórmula de la teoría 01, sección 7, con ejemplos |
| [Performance Tips](https://wiki.python.org/moin/PythonSpeed/PerformanceTips) (en inglés) | La página clásica de la wiki de Python: estructuras, bucles y funciones incorporadas. Algunos consejos son antiguos: mídelos antes de aplicarlos |
| [What is NumPy?](https://numpy.org/doc/stable/user/whatisnumpy.html) (en inglés) | Por qué un array es más rápido que una lista, contado por NumPy. La teoría 05 |
| [NumPy: the absolute basics](https://numpy.org/doc/stable/user/absolute_beginners.html) (en inglés) | Crear arrays, `dtype`, `shape`, operaciones y máscaras. Para adelantar la semana 23 |
| [Optimizing code](https://lectures.scientific-python.org/advanced/optimizing/index.html) (en inglés) | De las Scientific Python Lectures: medir, perfilar y vectorizar, con el mismo orden que esta semana |
