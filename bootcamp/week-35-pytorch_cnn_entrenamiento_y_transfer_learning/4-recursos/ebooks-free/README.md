# Ebooks gratuitos — Semana 35

Libros completos que sus autores publican gratis en la web, en inglés.

| Libro | Para qué |
|---|---|
| [Dive into Deep Learning](https://d2l.ai/chapter_convolutional-neural-networks/index.html) (Zhang, Lipton, Li y Smola) | El capítulo 7, redes convolucionales con código PyTorch: convolución, relleno, paso, canales y *pooling*. Y la sección [Fine-Tuning](https://d2l.ai/chapter_computer-vision/fine-tuning.html) del capítulo 14 para la teoría 04 |
| [Learn PyTorch for Deep Learning](https://www.learnpytorch.io/03_pytorch_computer_vision/) (Daniel Bourke) | Los capítulos 03 (visión por ordenador con una CNN) y [06 (transfer learning)](https://www.learnpytorch.io/06_pytorch_transfer_learning/), muy prácticos |
| [Understanding Deep Learning](https://udlbook.github.io/udlbook/) (Simon J. D. Prince) | El capítulo 10, redes convolucionales, con muchos dibujos; el 9, regularización: *dropout* y aumento de datos |
| [Neural Networks and Deep Learning](http://neuralnetworksanddeeplearning.com/chap6.html) (Michael Nielsen) | El capítulo 6: una CNN para dígitos escritos a mano, construida paso a paso |
| [Deep Learning](https://www.deeplearningbook.org/contents/convnets.html) (Goodfellow, Bengio y Courville) | El capítulo 9, redes convolucionales, con las matemáticas. Ampliación |
