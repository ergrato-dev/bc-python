# Ebooks gratuitos — Semana 29

Libros completos que sus autores publican gratis en la web, en inglés.

| Libro | Para qué |
|---|---|
| [Python for Data Analysis, 3.ª edición](https://wesmckinney.com/book/) (Wes McKinney) | Del creador de pandas: IPython y Jupyter (capítulo 2), lectura de archivos y bases de datos (capítulo 6) y limpieza de datos (capítulo 7). El más cercano a esta semana |
| [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/) (Jake VanderPlas) | El capítulo 1 explica IPython y Jupyter por dentro: magias, historial de entradas y salidas. Útil para entender qué no puede usar el notebook de tu proyecto |
| [The Turing Way](https://book.the-turing-way.org/) (comunidad The Turing Way) | Un libro colaborativo sobre investigación reproducible: datos, entornos, control de versiones y revisión de código |
