# Webgrafía — Semana 29

Casi todo en inglés, de la documentación oficial de cada proyecto. Las guías siguen la última versión; si algo no coincide con JupyterLab 4.6 o pandas 3.1, manda lo que ves al ejecutar.

| Recurso | Para qué |
|---|---|
| [JupyterLab Documentation](https://jupyterlab.readthedocs.io/en/stable/) | La interfaz, los atajos, los kernels y las extensiones. La teoría 02 |
| [Jupyter Server: Security](https://jupyter-server.readthedocs.io/en/latest/operators/security.html) | El token, las contraseñas y los notebooks confiables. La teoría 02, sección 9, y la 05, sección 3 |
| [The Notebook file format](https://nbformat.readthedocs.io/en/latest/format_description.html) | Qué guarda un `.ipynb`, clave a clave. La teoría 02, sección 5, y el ejercicio 02 |
| [nbclient](https://nbclient.readthedocs.io/en/latest/) | Ejecutar notebooks desde Python. Los ejercicios 02 y 04 |
| [nbconvert: Using as a command line tool](https://nbconvert.readthedocs.io/en/latest/usage.html) | `--clear-output`, `--execute` y los preprocesadores del gancho. La teoría 05, sección 4 |
| [pandas: `read_sql`](https://pandas.pydata.org/docs/reference/api/pandas.read_sql.html) | `params`, `dtype`, `chunksize` y qué acepta como consulta. La teoría 04 |
| [pandas: `DataFrame.to_sql`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.to_sql.html) | `if_exists`, `index` y los tipos de la tabla creada. El ejercicio 03, paso 6 |
| [pandas: `read_csv`](https://pandas.pydata.org/docs/reference/api/pandas.read_csv.html) | `keep_default_na`, `na_values` y la lista de textos que lee como hueco. La teoría 01, sección 4 |
| [SQLAlchemy: Working with Engines and Connections](https://docs.sqlalchemy.org/en/20/core/connections.html) | Conexiones, transacciones y `stream_results`. La teoría 04, sección 7 |
| [OWASP: SQL Injection](https://owasp.org/www-community/attacks/SQL_Injection) | Qué es una inyección de SQL, con ejemplos. El ejercicio 03, paso 4 |
| [uv: Managing dependencies](https://docs.astral.sh/uv/concepts/projects/dependencies/) | Los grupos de dependencias y `--group`. La teoría 05, sección 2 |
| [Docker Compose: Using profiles](https://docs.docker.com/compose/how-tos/profiles/) | Servicios que solo arrancan si los pides. La teoría 05, sección 3 |
| [Python: `hashlib`](https://docs.python.org/3/library/hashlib.html) | SHA-256 y las demás huellas. La teoría 03, sección 3 |
| [The Turing Way: Guide for Reproducible Research](https://book.the-turing-way.org/reproducible-research/reproducible-research) | Qué es la reproducibilidad, y cómo la consiguen equipos de investigación. La teoría 03 |
| [Colab: notebooks desde GitHub](https://colab.research.google.com/github/googlecolab/colabtools/blob/main/notebooks/colab-github-demo.ipynb) | Abrir y guardar notebooks de GitHub en Colab; el botón "Abrir en Colab". La teoría 05, sección 6 |
| [Colab: preguntas frecuentes](https://research.google.com/colaboratory/faq.html) | Límites de uso, dónde se guardan tus archivos y qué pasa con ellos |
