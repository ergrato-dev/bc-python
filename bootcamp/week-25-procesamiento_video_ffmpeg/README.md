🎥 Semana 25: Procesamiento de Video con FFmpeg

> **Fase 3 — Automatización y Pipelines de Media** · _Mid-level → Senior_

## 🎯 Objetivos de Aprendizaje

> 🚧 **Contenido en desarrollo.** Ver el [plan de expansión completo](../../docs/expansion-zero-to-master.md).

Al finalizar esta semana, serás capaz de:

- 🔲 ffmpeg-python: wrapper Pythónico de FFmpeg
- 🔲 Transcodificación: H.264, H.265, AV1, ProRes
- 🔲 Generación de proxies y previews para edición
- 🔲 Extracción de clips, stills y thumbnails de video
- 🔲 Pipeline de post-producción: ingest → proxy → web → archive
