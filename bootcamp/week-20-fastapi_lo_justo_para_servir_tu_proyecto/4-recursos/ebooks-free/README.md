# Ebooks gratuitos — Semana 20

| Libro | Qué leer esta semana |
|---|---|
| [Architecture Patterns with Python](https://www.cosmicpython.com/book/preface.html) (en inglés, libre en la web) | De Harry Percival y Bob Gregory. Cómo separar el dominio de la base de datos y de la API, que es lo que hacen tu `core` y tu `api.py`. Esta semana, el capítulo 4, ["Our First Use Case: Flask API and Service Layer"](https://www.cosmicpython.com/book/chapter_04_service_layer.html): usa Flask, pero la idea es la misma |
| [High Performance Browser Networking](https://hpbn.co/) (en inglés, libre en la web) | De Ilya Grigorik. Qué pasa en la red entre `curl` y uvicorn: TCP, la latencia y por qué reutilizar conexiones. Para más adelante: los capítulos 2, "Building Blocks of TCP", y 11, "HTTP/1.X" |
| [The Twelve-Factor App](https://12factor.net/es/) (en español, libre en la web) | Doce reglas para servicios que se despliegan. Esta semana, "III. Configuración" (la URL en el entorno, no en el código), "VI. Procesos" y "VII. Asignación de puertos": por qué `servir` recibe el puerto y la API no guarda nada en memoria |
