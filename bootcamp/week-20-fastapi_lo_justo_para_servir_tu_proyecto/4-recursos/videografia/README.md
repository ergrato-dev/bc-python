# Videografía — Semana 20

| Vídeo o canal | Qué ver |
|---|---|
| [How to Use FastAPI: A Detailed Python Tutorial](https://www.youtube.com/watch?v=SORiTsvnU28) (ArjanCodes, en inglés) | Una API de principio a fin con FastAPI. Compara cómo organiza las rutas, los modelos y el acceso a datos con tu `api.py` y tu `core` |
| [FastAPI Course for Beginners](https://www.youtube.com/watch?v=tLKKmouUams) (freeCodeCamp, en inglés) | Un curso largo desde cero. Útil por partes: busca en el índice los parámetros, el cuerpo y los códigos de respuesta |
| [Python API Development](https://www.youtube.com/watch?v=0sOvCWFmrtA) (freeCodeCamp, en inglés) | Un curso muy largo de APIs con FastAPI y PostgreSQL. No lo veas entero: usa su índice como mapa de lo que viene después, y de lo que trata `bc-fastapi` |
| [Sebastián Ramírez](https://www.youtube.com/@tiangolo) (en inglés) | El canal del autor de FastAPI |
| [PyCon US](https://www.youtube.com/@PyConUS) | Busca "FastAPI", "ASGI" o "async web": charlas sobre servidores asíncronos y sobre cómo probar APIs |
