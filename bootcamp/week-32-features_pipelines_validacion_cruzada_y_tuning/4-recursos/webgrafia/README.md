# Webgrafía — Semana 32

Casi todo en inglés, de la documentación oficial de cada proyecto. Las guías siguen la última versión; si algo no coincide con scikit-learn 1.9, manda lo que ves al ejecutar.

| Recurso | Para qué |
|---|---|
| [scikit-learn: Preprocessing data](https://scikit-learn.org/stable/modules/preprocessing.html) | `StandardScaler`, `OneHotEncoder` y el resto de transformadores. La teoría 01 |
| [scikit-learn: Imputation of missing values](https://scikit-learn.org/stable/modules/impute.html) | `SimpleImputer`, `add_indicator` y otras formas de rellenar. La teoría 01, sección 5 |
| [scikit-learn: Pipelines and composite estimators](https://scikit-learn.org/stable/modules/compose.html) | `Pipeline`, `ColumnTransformer`, `named_steps` y el doble guion bajo. La teoría 02 |
| [scikit-learn: Common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html) | La fuga de preparar fuera del pipeline, con ejemplos. La teoría 02, sección 4 |
| [scikit-learn: Cross-validation](https://scikit-learn.org/stable/modules/cross_validation.html) | `cross_val_score`, `cross_validate` y todos los repartos: `KFold`, `GroupKFold`, `TimeSeriesSplit`. La teoría 03 |
| [scikit-learn: Visualizing cross-validation behavior](https://scikit-learn.org/stable/auto_examples/model_selection/plot_cv_indices.html) | Cada forma de repartir, dibujada fila a fila. La teoría 03 y el ejercicio 03 |
| [scikit-learn: Validation curves](https://scikit-learn.org/stable/modules/learning_curve.html) | `validation_curve` y `learning_curve`, con gráficos. La teoría 04, sección 3 |
| [scikit-learn: Tuning the hyper-parameters](https://scikit-learn.org/stable/modules/grid_search.html) | `GridSearchCV`, `RandomizedSearchCV` y cómo leer `cv_results_`. La teoría 04 |
| [scikit-learn: Nested versus non-nested cross-validation](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html) | Cuánto engaña `best_score_`, repetido treinta veces. La teoría 05 |
| [MLU-Explain: Cross-Validation](https://mlu-explain.github.io/cross-validation/) | Los pliegues, animados. La teoría 03 |
| [MLU-Explain: The Bias Variance Tradeoff](https://mlu-explain.github.io/bias-variance/) | Por qué regularizar ayuda, de forma interactiva. La teoría 04, sección 2 |
| [Validación cruzada](https://es.wikipedia.org/wiki/Validaci%C3%B3n_cruzada) (en español) | k pliegues y dejar uno fuera. La teoría 03 |
| [Cross-validation (statistics)](https://en.wikipedia.org/wiki/Cross-validation_(statistics)) | Más formas de repartir, la anidada y sus problemas. Las teorías 03 y 05 |
| [Feature engineering](https://en.wikipedia.org/wiki/Feature_engineering) | Qué es preparar entradas y sus técnicas habituales. La teoría 01 |
| [Hyperparameter optimization](https://en.wikipedia.org/wiki/Hyperparameter_optimization) | Rejilla, azar y otras búsquedas. La teoría 04 |
| [Calmcode: scikit-learn](https://calmcode.io/course/scikit-learn/introduction) | Vídeos cortos sobre pipelines y `GridSearchCV`. Repaso de la semana |
