# Webgrafía — Semana 36

Casi todo en inglés, de la documentación oficial de cada proyecto. Las guías siguen la última versión; si algo no coincide con `transformers` 5.22 o `tokenizers` 0.23, manda lo que ves al ejecutar.

| Recurso | Para qué |
|---|---|
| [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) | El curso oficial: pipelines, tokenizadores, modelos y afinar, con código. Las teorías 01, 03 y 04 |
| [Hugging Face: Tokenizers, quicktour](https://huggingface.co/docs/tokenizers/quicktour) | Entrenar un tokenizador BPE desde cero, como `language.tokenizer`. La teoría 01, sección 5 |
| [Hugging Face: Summary of the tokenizers](https://huggingface.co/docs/transformers/tokenizer_summary) | BPE, WordPiece, Unigram y SentencePiece, comparados. La teoría 01, sección 6 |
| [Hugging Face: Pipelines](https://huggingface.co/docs/transformers/main_classes/pipelines) | Las tareas de `pipeline` y sus opciones. La teoría 04, sección 4 |
| [Hugging Face: Fine-tuning](https://huggingface.co/docs/transformers/training) | Afinar un modelo para clasificar texto, con `Trainer` o con un bucle propio como el del ejercicio 04 |
| [Hugging Face: Model cards](https://huggingface.co/docs/hub/model-cards) | Qué cuenta la ficha de un modelo. La teoría 04, sección 1 |
| [Hugging Face: Security](https://huggingface.co/docs/hub/security) | `pickle`, `safetensors` y el código remoto. La teoría 04, sección 2 |
| [safetensors](https://huggingface.co/docs/safetensors/index) | El formato de pesos que no ejecuta código. El ejercicio 04, paso 6 |
| [The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/) (Jay Alammar) | El Transformer en dibujos: consultas, claves, valores, cabezas y posiciones. Las teorías 02 y 03 |
| [The Annotated Transformer](https://nlp.seas.harvard.edu/annotated-transformer/) (Harvard NLP) | El artículo de 2017 línea a línea, con el código en PyTorch. Ampliación de la teoría 03 |
| [Attention Is All You Need](https://arxiv.org/abs/1706.03762) (Vaswani y otros, 2017) | El artículo original. La teoría 03, sección 1 |
| [PyTorch: TransformerEncoderLayer](https://docs.pytorch.org/docs/stable/generated/torch.nn.TransformerEncoderLayer.html) | El bloque de tu `Encoder` y sus parámetros. La teoría 03 |
| [PyTorch: scaled_dot_product_attention](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.scaled_dot_product_attention.html) | La atención en una operación, con sus máscaras. La teoría 02, secciones 4 y 5 |
| [PyTorch: MultiheadAttention](https://docs.pytorch.org/docs/stable/generated/torch.nn.MultiheadAttention.html) | Las cabezas, `batch_first` y los pesos. La teoría 02, sección 6 |
| [scikit-learn: Text feature extraction](https://scikit-learn.org/stable/modules/feature_extraction.html#text-feature-extraction) | Bolsa de palabras y TF-IDF con un clasificador. La teoría 01, secciones 2 y 3 |
| [Sentence Transformers](https://sbert.net/) | Frases a vectores y búsqueda semántica. El ejercicio 03, y la semana 38 |
| [Procesamiento de lenguajes naturales](https://es.wikipedia.org/wiki/Procesamiento_de_lenguajes_naturales) (en español) | Qué es el NLP y su historia. La teoría 01 |
| [Transformador (modelo de aprendizaje automático)](https://es.wikipedia.org/wiki/Transformador_(modelo_de_aprendizaje_autom%C3%A1tico)) (en español) | El Transformer y sus familias. La teoría 03 |
