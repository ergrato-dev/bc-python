# Webgrafía — Semana 23

| Recurso | Para qué |
|---|---|
| [NumPy: the absolute basics for beginners](https://numpy.org/doc/stable/user/absolute_beginners.html) (en inglés) | La guía oficial de inicio: crear arrays, `shape`, `dtype`, índices, operaciones y resúmenes. Repasa toda la semana en una página |
| [Data types](https://numpy.org/doc/stable/user/basics.types.html) (en inglés) | Los `dtype` de NumPy, sus límites y cómo se desbordan los enteros. La teoría 01, sección 5 |
| [Indexing on ndarrays](https://numpy.org/doc/stable/user/basics.indexing.html) (en inglés) | Índices, cortes, listas de posiciones y máscaras, con todos los casos. La teoría 02 |
| [Copies and views](https://numpy.org/doc/stable/user/basics.copies.html) (en inglés) | Qué operaciones dan una vista y cuáles una copia, y cómo saberlo con `base`. La teoría 02, sección 3 |
| [Broadcasting](https://numpy.org/doc/stable/user/basics.broadcasting.html) (en inglés) | La regla de las formas, con dibujos de los casos que encajan y los que no. La teoría 03 |
| [Random Generator](https://numpy.org/doc/stable/reference/random/generator.html) (en inglés) | `default_rng` y sus métodos: `normal`, `uniform`, `integers`, `choice`... La teoría 04, sección 1 |
| [Statistics](https://numpy.org/doc/stable/reference/routines.statistics.html) (en inglés) | Todas las funciones de resumen: medias, percentiles, histogramas y sus versiones `nan*` |
| [`numpy.percentile`](https://numpy.org/doc/stable/reference/generated/numpy.percentile.html) (en inglés) | Los métodos para interpolar entre valores, por si tus cuartiles no coinciden con los de otra herramienta |
| [`numpy.histogram`](https://numpy.org/doc/stable/reference/generated/numpy.histogram.html) (en inglés) | Los bordes de los intervalos, `bins` como número o como lista, y por qué el último incluye su borde derecho |
| [Typing (`numpy.typing`)](https://numpy.org/doc/stable/reference/typing.html) (en inglés) | `NDArray` y las anotaciones de NumPy para mypy. La teoría 05, sección 1 |
| [Test support (`numpy.testing`)](https://numpy.org/doc/stable/reference/routines.testing.html) (en inglés) | `assert_allclose`, `assert_array_equal` y sus tolerancias. La teoría 05, sección 3 |
| [PEP 649](https://peps.python.org/pep-0649/) (en inglés) | Las anotaciones que se evalúan cuando alguien las pide, desde Python 3.14. Por qué funciona el bloque `TYPE_CHECKING` de la CLI |
| [NumPy tutorials](https://numpy.org/numpy-tutorials/) (en inglés) | Casos completos con datos reales. Elige uno de análisis para practicar después de la semana |
