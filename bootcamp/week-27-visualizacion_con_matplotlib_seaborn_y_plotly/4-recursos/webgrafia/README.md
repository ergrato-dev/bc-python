# Webgrafía — Semana 27

Casi todo en inglés, de la documentación oficial de cada proyecto. Las guías siguen la última versión; si algo no coincide con matplotlib 3.11, seaborn 0.13 o plotly 7, manda lo que ves al ejecutar.

| Recurso | Para qué |
|---|---|
| [matplotlib: Quick start guide](https://matplotlib.org/stable/users/explain/quick_start.html) | `Figure`, `Axes` y artistas, con la figura de la anatomía de un gráfico. La teoría 01 |
| [matplotlib: Matplotlib Application Interfaces](https://matplotlib.org/stable/users/explain/figure/api_interfaces.html) | La interfaz de objetos frente a `pyplot`, explicada por sus autores. La teoría 01, sección 5 |
| [matplotlib: Embed in a web application server](https://matplotlib.org/stable/gallery/user_interfaces/web_application_server_sgskip.html) | Dibujar con `Figure` sin `pyplot` en un servidor, y por qué. La teoría 05, sección 2 |
| [matplotlib: Customizing with style sheets and rcParams](https://matplotlib.org/stable/users/explain/customizing.html) | `rcParams`, `rc_context` y los estilos. La teoría 05, sección 4 |
| [matplotlib: Choosing Colormaps](https://matplotlib.org/stable/users/explain/colors/colormaps.html) | Paletas secuenciales, divergentes y categóricas, y por qué no `jet`. La teoría 02, sección 5 |
| [matplotlib: Examples](https://matplotlib.org/stable/gallery/index.html) | La galería: un ejemplo con código para casi cualquier gráfico |
| [seaborn: An introduction to seaborn](https://seaborn.pydata.org/tutorial/introduction.html) | Un recorrido corto por lo que hace seaborn. La teoría 03 |
| [seaborn: Overview of seaborn plotting functions](https://seaborn.pydata.org/tutorial/function_overview.html) | Funciones de ejes y de figura, y cuándo usar cada una. La teoría 03, sección 4 |
| [seaborn: Data structures accepted by seaborn](https://seaborn.pydata.org/tutorial/data_structure.html) | Datos largos y anchos. La teoría 03, sección 2 |
| [seaborn: Statistical estimation and error bars](https://seaborn.pydata.org/tutorial/error_bars.html) | Qué significa cada `errorbar`: confianza, desviación típica... La teoría 03, sección 3 |
| [plotly: Plotly Express in Python](https://plotly.com/python/plotly-express/) | Todas las funciones de plotly express, con ejemplos. La teoría 04 |
| [plotly: The Figure Data Structure in Python](https://plotly.com/python/figure-structure/) | `data`, `layout` y las trazas. La teoría 04, sección 3 |
| [plotly: Interactive HTML Export in Python](https://plotly.com/python/interactive-html-export/) | `write_html` e `include_plotlyjs`. El ejercicio 04, paso 3 |
| [plotly: Static Image Export in Python](https://plotly.com/python/static-image-export/) | Kaleido y lo que necesita para escribir un PNG |
| [From Data to Viz](https://www.data-to-viz.com/) | Un árbol de decisión para elegir el gráfico según tus datos, con los errores típicos de cada uno. La teoría 02 |
