# Webgrafía — Semana 33

Casi todo en inglés, de la documentación oficial de cada proyecto. Las guías siguen la última versión; si algo no coincide con scikit-learn 1.9, manda lo que ves al ejecutar.

| Recurso | Para qué |
|---|---|
| [scikit-learn: Decision Trees](https://scikit-learn.org/stable/modules/tree.html) | Cómo crece un árbol, sus criterios de impureza, `export_text` y `plot_tree`. La teoría 01 |
| [scikit-learn: Ensembles](https://scikit-learn.org/stable/modules/ensemble.html) | Bosques aleatorios, *bagging*, `GradientBoosting*` y `HistGradientBoosting*`, con sus hiperparámetros. Las teorías 02 y 03 |
| [scikit-learn: Early stopping in Gradient Boosting](https://scikit-learn.org/stable/auto_examples/ensemble/plot_gradient_boosting_early_stopping.html) | Cuántos árboles ahorra la parada temprana, con gráficos. La teoría 03, sección 3 |
| [scikit-learn: Permutation feature importance](https://scikit-learn.org/stable/modules/permutation_importance.html) | Qué mide `permutation_importance` y en qué se diferencia de la impureza. La teoría 02, sección 4 |
| [scikit-learn: Permutation Importance vs Random Forest Feature Importance](https://scikit-learn.org/stable/auto_examples/inspection/plot_permutation_importance.html) | Una columna al azar que la impureza premia y la permutación no: el ejercicio 02, con el Titanic |
| [scikit-learn: Clustering](https://scikit-learn.org/stable/modules/clustering.html) | KMeans y los demás métodos (`DBSCAN`, jerárquico…), con un dibujo de cada uno. La teoría 04 |
| [scikit-learn: Selecting the number of clusters with silhouette analysis](https://scikit-learn.org/stable/auto_examples/cluster/plot_kmeans_silhouette_analysis.html) | La silueta fila a fila, para varios `k`. La teoría 04, sección 4 |
| [scikit-learn: Decomposing signals in components](https://scikit-learn.org/stable/modules/decomposition.html) | PCA y sus variantes. La teoría 05 |
| [MLU-Explain: Decision Trees](https://mlu-explain.github.io/decision-tree/) | Cómo elige cada corte, de forma interactiva. La teoría 01 |
| [MLU-Explain: Random Forest](https://mlu-explain.github.io/random-forest/) | *Bagging* y la media de muchos árboles, animados. La teoría 02 |
| [Setosa: Principal Component Analysis Explained Visually](https://setosa.io/ev/principal-component-analysis/) | PCA en dos y tres dimensiones, girando los datos. La teoría 05 |
| [Árbol de decisión](https://es.wikipedia.org/wiki/%C3%81rbol_de_decisi%C3%B3n) (en español) | Qué es un árbol de decisión, más allá del aprendizaje automático. La teoría 01 |
| [K-medias](https://es.wikipedia.org/wiki/K-medias) (en español) | El algoritmo de KMeans y sus límites. La teoría 04 |
| [Gradient boosting](https://en.wikipedia.org/wiki/Gradient_boosting) | El algoritmo con fórmulas, y su historia. La teoría 03 |
| [Silhouette (clustering)](https://en.wikipedia.org/wiki/Silhouette_(clustering)) | La fórmula de la silueta, con un ejemplo. La teoría 04, sección 4 |
| [Principal component analysis](https://en.wikipedia.org/wiki/Principal_component_analysis) | PCA con más detalle: varianza explicada y cuántas componentes. La teoría 05 |
