# Videografía — Semana 06

| Canal | Qué buscar |
|---|---|
| [CS Dojo](https://www.youtube.com/@CSDojo) | Busca "Big O notation": una introducción corta, con ejemplos en Python, a contar pasos y comparar órdenes |
| [Corey Schafer](https://www.youtube.com/@coreyms) | Busca "itertools" y "timeit": un recorrido por el módulo con ejemplos en el REPL |
| [mCoding](https://www.youtube.com/@mCoding) | Busca "collections" o "deque" para ver cuándo cambiar de colección mejora el orden de un programa |
| [NeetCode](https://www.youtube.com/@NeetCode) | Busca "binary search" y "sliding window": los dos patrones de esta semana, resueltos en Python paso a paso |

Elige un vídeo y comprueba con `timeit` una afirmación que haga sobre lo que tarda algo; si te sirve, llévala a tu *pull request*.
