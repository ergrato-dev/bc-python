# Webgrafía — Semana 31

Casi todo en inglés, de la documentación oficial de cada proyecto. Las guías siguen la última versión; si algo no coincide con scikit-learn 1.9, manda lo que ves al ejecutar.

| Recurso | Para qué |
|---|---|
| [scikit-learn: Getting Started](https://scikit-learn.org/stable/getting_started.html) | `fit`, `predict`, estimadores y evaluación en una página. La teoría 01 |
| [scikit-learn: Linear Models](https://scikit-learn.org/stable/modules/linear_model.html) | Mínimos cuadrados y regresión logística, con sus opciones. Las teorías 03 y 04 |
| [scikit-learn: `train_test_split`](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.train_test_split.html) | `test_size`, `random_state` y `stratify`. La teoría 02 y `learning.split` |
| [scikit-learn: `DummyClassifier`](https://scikit-learn.org/stable/modules/generated/sklearn.dummy.DummyClassifier.html) | Las estrategias de la referencia: `most_frequent`, `stratified`, `uniform`. La teoría 02, sección 4 |
| [scikit-learn: Metrics and scoring](https://scikit-learn.org/stable/modules/model_evaluation.html) | Todas las métricas de regresión y clasificación, con sus fórmulas. Las teorías 03 y 04 |
| [scikit-learn: Underfitting vs. Overfitting](https://scikit-learn.org/stable/auto_examples/model_selection/plot_underfitting_overfitting.html) | Polinomios de grado 1, 4 y 15: el ejemplo de la teoría 02, con gráficos |
| [scikit-learn: Common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html) | Fugas de datos y semillas, en la guía oficial. La teoría 05 |
| [scikit-learn: Glossary](https://scikit-learn.org/stable/glossary.html) | Qué es un estimador, `fit`, un atributo con `_` final. Para consultar |
| [pandas: `get_dummies`](https://pandas.pydata.org/docs/reference/api/pandas.get_dummies.html) | One-hot, `dtype` y `prefix`. La teoría 03, sección 2 |
| [MLU-Explain: Train, Test, and Validation Sets](https://mlu-explain.github.io/train-test-validation/) | El reparto, animado. La teoría 02 |
| [MLU-Explain: Precision & Recall](https://mlu-explain.github.io/precision-recall/) | Mueve el umbral y mira cómo cambian las dos. La teoría 04 y el ejercicio 03, paso 4 |
| [Leakage (machine learning)](https://en.wikipedia.org/wiki/Leakage_(machine_learning)) | Tipos de fuga y casos reales. La teoría 05 |
| [Matriz de confusión](https://es.wikipedia.org/wiki/Matriz_de_confusi%C3%B3n) (en español) | Las cuatro casillas y las métricas que salen de ellas. La teoría 04, sección 3 |
| [Precision and recall](https://en.wikipedia.org/wiki/Precision_and_recall) | Las fórmulas, F1 y su relación con el umbral. La teoría 04, sección 4 |
| [Google: Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) | Curso corto con ejercicios interactivos: regresión lineal y logística, clasificación y datos. Repaso de la semana |
