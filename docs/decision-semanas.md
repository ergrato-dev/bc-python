# ADR: duración y ritmo

- Dedicación: 18 h por semana. La tabla de tiempos de cada README de semana suma exactamente 18 h; si suma más, se recorta alcance.
- Duración: 42 semanas, 756 h, en 5 fases (la malla completa está en el README). El número de semanas lo fija la completitud y pertinencia del temario, no la extensión de otros bootcamps.
- Peso del temario: fases 4 y 5 (data science, ML e IA) suman 20 semanas, porque es el uso dominante de Python hoy.
- Solapes: testing, PostgreSQL, HTTP, CI y FastAPI se enseñan lo justo desde la óptica de Python y se enlazan a `bc-testing`, `bc-sql`, `bc-fastapi`, `bc-observability` y `bc-github-actions`.
- Versión anterior (36 semanas x 6 h, dominio único Studio BC): conservada en el tag `legacy-36w`, usada solo como materia prima.
